# New Emi Institute - Plataforma Web 🌐

![Logo New Emi](/img/logo.png)

Sitio web oficial de **New Emi Institute**, expertos en la enseñanza de idiomas con más de 20 años de trayectoria y certificación avalada por la **UTN**. Esta plataforma ofrece una experiencia moderna e intuitiva para alumnos y empresas interesadas en capacitación lingüística.

## 🚀 Características del Proyecto
* **Diseño Moderno**: Interfaz basada en *Glassmorphism* y paleta de colores corporativa (Purples).
* **Bento Grid Layout**: Organización visual atractiva para las categorías de cursos (Children, Adults, etc.).
* **In-Company Training**: Sección dedicada a soluciones corporativas con integración de logos de clientes destacados.
* **Totalmente Responsivo**: Optimizado para dispositivos móviles con menú hamburguesa funcional.
* **Canales de Contacto**: Integración directa con WhatsApp y formularios de consulta.

## 🛠️ Tecnologías Utilizadas
* **HTML5 & CSS3**: Estructura y estilos personalizados utilizando variables CSS para coherencia de marca.
* **JavaScript (Vanilla)**: Lógica para el menú móvil, dropdowns y efectos de scroll.
* **Bootstrap Icons**: Librería de iconografía para una interfaz clara y moderna.
* **Animate.css**: Animaciones de entrada suaves para mejorar la experiencia de usuario.
